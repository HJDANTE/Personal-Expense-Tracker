# Personal Expense Tracker v1.1

A beginner-friendly Python command-line application for managing personal income and expenses.

## Features

- Add income transactions.
- Add expense transactions.
- Assign expenses to different categories:
  - Food
  - Transport
  - Education
  - Entertainment
  - Other
- View transaction history.
- Calculate total income and expenses.
- Display current account balance.
- View expenses by category.
- Save transaction data using JSON.
- Load previously saved transactions when the application starts.

## Technologies Used

- Python
- JSON
- Built-in Python functions and data structures

## Data Storage

The application uses a JSON file (`transaction.json`) to store transaction records.

Previously saved data is loaded when the application starts, allowing transaction information to remain available between sessions.

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run the Python file:

```bash
python "Expense Tracker v1.1.py"
```
